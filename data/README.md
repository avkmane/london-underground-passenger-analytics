# Data

The analysis was validated against the original coursework datasets `hourly_entries.csv` and `hourly_exits.csv` (268 stations × 21 hourly periods each). The public portfolio repository does not redistribute the original coursework source files. Place authorised copies in `data/raw/` to reproduce the full pipeline.

Expected files:

- `data/raw/hourly_entries.csv`
- `data/raw/hourly_exits.csv`

The verified aggregate results produced from those files are documented in the root README and `reports/executive_summary.md`.
